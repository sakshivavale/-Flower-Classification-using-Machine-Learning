# 🌸 Flower Classification using Machine Learning

This project focuses on classifying Iris flowers into different species using Machine Learning. It uses flower measurements, such as sepal length, sepal width, petal length, and petal width, to predict the flower species.

The project helps understand the basic steps of a Machine Learning workflow, including data analysis, data visualization, model training, and model evaluation.

## 🎯 Project Objectives

- Understand the Iris flower dataset.
- Explore and analyze flower measurements.
- Visualize data using graphs and charts.
- Build Machine Learning classification models.
- Evaluate model performance and predict flower species.

## 📊 Dataset Information

The Iris dataset contains measurements of three Iris flower species:

- **Iris-setosa**
- **Iris-versicolor**
- **Iris-virginica**

### Features Used

| Feature | Description |
|---|---|
| Sepal Length | Length of the flower's sepal |
| Sepal Width | Width of the flower's sepal |
| Petal Length | Length of the flower's petal |
| Petal Width | Width of the flower's petal |
| Species | Name of the flower species to predict |

## 🛠️ Technologies Used

- **Matplotlib** – Data visualization

- **Scikit-learn** – Machine Learning algorithms

## ⚙️ Project Workflow

1. Load the Iris dataset.
2. Explore the dataset and understand its features.
3. Perform data analysis and visualization.
4. Prepare the data for model training.
5. Train a Machine Learning classification model.
6. Evaluate the model's performance.
7. Predict the species of Iris flowers using their measurements.

## 🤖 Machine Learning

This project explores flower classification as a **supervised learning** problem.

Supervised learning means training a model using data that already contains the correct answers.

Classification means predicting a category, such as Iris-setosa, Iris-versicolor, or Iris-virginica.
